Case studies / Tata 1mg

Lifting app downloads 55% and retention 35% at Tata 1mg

Tata 1mg sells medicines, lab tests and consultations to millions of Indian users. I led UX for the consumer app's growth work and, in parallel, set up the UX function for a new B2B warehouse management product.

Context

Consumer health, where a confusing step means a missed dose

The app covered medicine search, prescription upload and ordering, and lab test booking. Users ranged from first-time smartphone users to caregivers ordering for elderly parents.

What I owned: UX direction for onboarding and the core flows, the experiment plan with product, and the design system and service blueprints for the new B2B warehouse product. What the team shipped: who designed and built which parts

Stakes & problem

Users were installing, then dropping before their first order

Business problem. Acquisition spend was bringing users in, but too few completed a first order or came back. Add the baseline: e.g. D30 retention or onboarding drop-off rate

User problem. Search, prescription-to-order and lab booking each asked for information in a different way, and onboarding front-loaded questions before showing value.

Research

The prescription step was the real drop-off point

  • Finding 1: e.g. users abandoned at prescription upload, unsure what was acceptable

    Decision it changed: e.g. added examples and a guided capture step

  • Finding 2: e.g. new users wanted to search before signing up

    Decision it changed: e.g. deferred registration until checkout

Architecture & iteration

Mobile-first onboarding, then one consistent pattern for every order type

  • Call 1: Show value before asking for data

    Describe the onboarding change and what you cut

  • Call 2: One ordering pattern across medicines and lab tests

    Search, prescription-to-order and lab booking were rebuilt on shared steps so users learned the flow once.

  • Call 3: Stand up B2B UX properly from day one

    For the warehouse product I set up the UX function, a design system and service blueprints before screens, so operations and engineering shared one model of the workflow.

Iteration. A variant you tested that lost, and what you learned from it.

Solution

A shorter path from install to first order

Accessibility proof

  • Touch targets

    Primary actions at least 44×44 px for one-handed use.

  • Readable text

    Dosage and price text meet 4.5:1 contrast and support system font scaling.

Impact

+55% downloads, +35% retention, +20% task completion
