## Claude Code skill

`.claude/skills/executive-ux-portfolio/SKILL.md` teaches Claude Code how to draft and review case studies for senior design leadership roles. It loads automatically when you open this repo in Claude Code, and you can call it directly with `/executive-ux-portfolio`.
